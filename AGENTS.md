# AGENTS.md

## Стиль документации

- Формат: техническая документация.
- Пиши простым и понятным языком.
- Объясняй термины при первом появлении.
- Аудитория: читатели с техническим бэкграундом, включая новичков в локальном инференсе LLM.
- Держи шаги воспроизводимыми: команды, ожидаемый результат, проверка.
- Используй короткие разделы и списки.
- Не используй emdash.
- Не используй кавычки елочки.
- Не используй двойное подчеркивание для выделения.
- Не строь текст на антитезах.
